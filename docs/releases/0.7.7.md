# Pod 0.7.7 — Skills comparison search

This release of the partiizan/pod fork adds live skill-name filtering to **Skills → Compare** (issue #1).
Type a partial name such as `jump drive` to see matching skills across all selected pilots. Matching groups expand
automatically; **Clear search** restores the full catalog and your previous group expansion state. The search stays
visible while scrolling. Large comparisons now scroll horizontally instead of squeezing all pilot columns together.

Filtering uses local data and makes no additional ESI calls. Existing completed-training corrections, pilot totals,
and skill levels are preserved. The Add Pilot search remains separate.

## Downloads

- Windows x64: NSIS `.exe` installer or WiX `.msi` installer.
- Apple Silicon Mac: `aarch64` DMG.
- Intel Mac: `x86_64`/`x64` DMG.
- `SHA256SUMS.txt`: checksums for all four installers.

These fork installers are unsigned and the macOS builds are not notarized. Windows/macOS may display publisher or
Gatekeeper warnings. Automatic updates are disabled in these packages; install future updates from this fork's
Releases page. Existing app identity and data locations are retained for compatibility with your current installation.

Native automated tests and package checks gate publication. Interactive installation, EVE SSO, and live character
sync still need hands-on verification on your machines. No blanket claim of current compatibility for all ESI
endpoints is made by this release; this feature leaves the existing compatibility date unchanged.

Implementation and release preparation were AI-assisted at the repository owner's request.
